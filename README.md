### Важно перед проверкой (очистка кэша PWA)
В Task 7 используется Service Worker для офлайн-режима, поэтому при первом открытии или после обновлений браузер может загружать старую закэшированную версию сайта (из-за чего кнопки навигации могут вести на старые пути).

**Чтобы всё работало корректно:**
1. Откройте https://abylaybeisen.github.io/React/task7/ в **режиме Инкогнито** (`Ctrl + Shift + N` / `Cmd + Shift + N`) — там кэш чистый и все маршруты работают сразу.
2. Или в обычном окне сделайте жёсткое обновление страницы (`Ctrl + Shift + R` / `Cmd + Option + R`), либо очистите кэш сайта в DevTools (`Application` → `Storage` → `Clear site data`).
